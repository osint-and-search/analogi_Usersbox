## Что умел UsersBox и зачем он нужен
UsersBox — Telegram-бот (**В НАСТОЯЩЕЕ ВРЕМЯ НЕ РАБОТАЕТ - альтернативы ниже**), предназначенный для OSINT-задач и быстрого извлечения информации. Сервис был полезен тем, кому требовалось за короткое время собрать данные о человеке по разным ключам. Среди основных функций можно отметить следующие:

* Поиск сведений по телефонному номеру.
* Проверка адресов электронной почты.
* Поиск аккаунтов в социальных сетях через никнеймы.
* Проверка попадания данных в публичные утечки.
* Экспорт результатов и формирование отчётов.

Бот позволял выполнить ограниченное количество запросов бесплатно и давал возможность оценить работу перед оплатой.

## 🚨 Проблемы с пополнением баланса в ботах Telegram 🚨
Новые ограничения повлияли на работу Telegram-ботов и привели к появлению сложностей с оплатой.

Для решения задачи можно воспользоваться следующими способами:
* Пополнение банковской картой. У большинства ботов минимальный порог пополнения теперь равен 1000 рублям. Разумнее сразу вносить эту сумму или больше, чтобы получить бонусы и обеспечить себе длительный доступ.
* Оплата через Telegram Stars. Удобный вариант, поскольку звёзды можно приобрести напрямую в Telegram небольшой суммой через карту и сразу использовать для оплаты услуг бота.
* Криптовалютный кошелёк. В Telegram доступны [Официальный кошелек](https://t.me/wallet/start?startapp=ref-1-g__tgEbYk3k) и [Crypto Bot](https://t.me/send?start=r-ezc61), где можно купить криптовалюту картой и затем перевести средства на счёт бота.

Перечисленные методы позволяют сохранить доступ к функциям OSINT-ботов в Telegram.

## Зачем используют Userbox
Usersbox представляет собой инструмент для поиска сведений о людях и компаниях в открытых источниках. Его применяли в следующих сценариях:
* Проверка контактов — чтобы понять, кому принадлежит номер, почта или никнейм.
* Выявление мошенников — помогает обнаружить фейковые профили и подозрительные аккаунты.
* Восстановление контактов — иногда через бот удаётся найти старых знакомых или родственников по оставшимся следам.
* Сбор OSINT-информации — востребован аналитиками, журналистами и расследователями для быстрого сбора публичных данных.
* Проверка сотрудников и партнёров — компании используют его для предварительной оценки кандидатов и контрагентов.
* Поиск связанных аккаунтов — показывает, где ещё встречаются те же телефон, ник или адрес почты.
* Экономия времени — всё необходимое находится в одном месте, без необходимости вручную проверять множество сервисов.
